# 验收清单

## 提交前

- [ ] 本次作用范围、目标规则、结构、授权模式和当前可用权限已核对。
- [ ] 各原件身份、版本、链接和实际可读范围已登记。
- [ ] 覆盖表包含所有纳入范围的小节、图表和案例。每项标明新建、增补、证据、索引或待核实及理由。
- [ ] 已按问题、条件和来源范围核对候选条目。同题优先复用，目录占位保持可原位补全。
- [ ] 逐字引文、日期、数字、图例、指代及场景边界已回查。概括和建议正确标注。
- [ ] 正文、属性、链接文字和案例符合适用的匿名与出处要求。
- [ ] 现行内容与历史、待审和索引材料可区分。知识条目的字段与正文含义一致。
- [ ] 提案标识、版本、目标位置、当前表述、拟改内容和新依据齐全。

## 合入前及读回

- [ ] 批准来自有权确认的人本人，具体对应提案版本和条目。转述意见只作为复核线索。
- [ ] 已对照现行基线。前次已完成项标为重用；仍有实质冲突的目标单独待审。
- [ ] 只执行批准的动作。待删项默认留给用户；执行具体删除前核对规则许可及明确批准。原件内容与身份保持原样。
- [ ] 实际写入内容、字段、审核状态及关系已读回。与原件的追溯链打开或定位成功。
- [ ] 遇到未知或部分成功结果，先核对写入状态，再补剩余动作。
- [ ] 只读、待审、已读回生效、失败和待人工处理的项目分开。可用索引和当前未核实范围说明清楚。

## 测试场景

| 场景 | 看到什么算通过 |
| --- | --- |
| 两种结构与审核方式 | 同一批材料在单库和分库里都可查到同题条目、补齐占位并回查出处。字段和状态按各自映射。 |
| 目录式 | 知识页相对链接或稳定入口能定位资料和原件。 |
| 只读或缺规则 | 返回完整可粘贴稿或待核对稿。目标库不发生对应写入。 |
| 作者语义和出处 | 保留并列因素、案例条件和问句力度，区别可核实的原文缺口与未搜到内容。 |
| 部分批准和转述 | 只合入本人批准的具体条目与版本，剩余稿仍待处理。 |
| 删除 | 默认返回待删项和影响；只有规则和具体授权均成立时才执行对应删除。 |
| 超时重试及基线变化 | 先读回确认完成项，避免重复建页。只有冲突项重新复核。 |

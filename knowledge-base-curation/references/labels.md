# 判断内容与证据的性质

按语义判断，再映射到目标库的标签或段落标题。若目标库用散文或普通列表表达，在相关句子旁直接说明性质即可。

| 内容性质 | 判断方法 | 写法 |
| --- | --- | --- |
| 原文顺序 | 原文明确写出具备何种先后关系，并核实语气是固定要求、建议还是例子。 | 保留先后和力度。仅在读者能据此执行时写成步骤。 |
| 呈现顺序 | 条目按标题、段落或版面排列，原文只在介绍内容。 | 保持原文排列或用并列项目，并注明属于讲解顺序。 |
| 并列因素 | 同一条件下的多项检查、原因或因素，原文没有要求先后。 | 保留相关项。若原文同时要求逐项检查或给出门槛，一并写出。 |
| 案例顺序 | 某例的实际经过、拟定步骤或样稿结构。 | 给出案例前提，标清实际发生与计划的区别。 |
| 原文条件与案例条件 | 前者由原文说明何时适用，后者仅描述特定案例的背景或决策前提。 | 写在对应做法或案例旁。门槛不可脱离对象和范围。 |
| 整理概括、口径与建议 | 概括重述指定材料中有出处的内容；口径描述整理时采用的分类或统计方法；整理者建议只解释或应用已有证据。 | 分开写并注明身份。直接引文逐字核对，概括保留出处，把依已有证据得出的建议标为建议；范围外知识和经验不能填补缺口。 |
| 当前资料未找到与原文缺口 | 当前持有的材料没有证据，或者已查过匹配章节后确认原文未给条件、数值或步骤。 | 前者说「当前资料未找到」，后者说明核实过的范围和具体缺口。 |

直接引文连同原有标点一起核对。原句本身含引号时用独立引文块承载，避免为套入另一对引号而改动原文标点。按目标库规定匿名的部分显式标明。

**虚构示例**。手册写「交接单应核对设备、库存和人员」。可以记录三项并列检查。案例另写「甲班先盘点库存，再核查人员」，可作为甲班当时的处理顺序，保留标签或文字说明。若案例的第一句是「假如你只能准备一张表，你会写什么？」，保留它是引导思考的问句。
